# 网页版功能完整性清单

这份清单以当前项目后端接口、Web 页面和完整配置指南为基准，用来逐项补齐“金融分析的实力辅助”的网页能力。状态只表示当前代码检查结果，不代表功能已经经过线上验证。

## 状态说明

- **已有**：网页已有入口，并且已经连接到对应接口。
- **待核对**：网页或后端已有相关代码，但还需要通过实际操作确认完整链路。
- **需补网页入口**：后端能力已有，网页还没有清晰的管理入口。
- **需补后端/部署**：当前不能只靠网页完成，需要补服务、配置或部署链路。

## 当前最需要补的部分

1. 先完成一次**真实功能验收**：单股分析、批量分析、历史报告、问股、选股、回测、告警、持仓、认证。
2. 再补**设置中心**：新闻搜索、通知渠道、数据源优先级、配置导入导出和连接测试。
3. 处理**模型稳定性**：自动剔除不可用模型，减少无效重试，并显示当前分析停在哪一步。
4. 最后做**部署链路**：云服务器、域名、HTTPS、数据库备份、管理员登录和定时任务。

## 验收标准

每个功能完成后都记录以下结果：

- 网页入口是否能找到；
- 请求是否到达正确接口；
- 成功结果是否能展示；
- 失败、超时、限流和无数据时是否有清楚提示；
- 刷新页面或重新登录后数据是否仍然存在；
- 是否影响桌面端和已有 API；
- 是否有对应的使用说明和回滚方式。
