# 网页改版说明

`apps/dsa-web/` 是正式网页前端，继续调用现有 FastAPI 接口。根目录的 `index.html`、`styles.css`、`app.js` 是早期演示文件，暂时保留。

当前改版先覆盖通用导航框架与首页。产品名称为“金融分析的实力辅助”；网页默认使用白色主题，保留深色与跟随系统选项。股票输入以美股示例为先，大盘复盘在网页上默认选中美股；用户仍可选择其他市场或服务器默认。原有 A 股、港股和美股能力继续保留。

问股、持仓、AI 建议、选股、回测、告警、用量及设置页继续使用原有路由和接口。选股导航仅在后端启用选股功能后显示。模型、数据源、通知和认证仍通过原有设置与服务管理；尚未配置模型 API Key 时，首页会显示配置提醒，分析能力不能完整试跑。

后续逐页改造时，以现有页面功能和 API 契约为基准核对，不凭视觉改版删除功能。部署、模型接入和登录策略尚未在本阶段调整。
